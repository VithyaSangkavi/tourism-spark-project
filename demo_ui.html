Pipeline Method

This is the technical story to explain in the presentation or video.

1. Spark IngestionLoad multiline quoted CSV reviews, infer schema, clean invalid districts, and normalize review text.
2. Feature EngineeringCreate sentiment scores, word engagement, recency segments, and travel theme labels at review level.
3. Analytics LayerAggregate by destination, district, and theme using Spark SQL windows and confidence-weighted scoring.
4. Recommender LayerBuild TF-IDF destination profiles with Spark ML and rank similar places using a hybrid similarity score.
