Big Data Analytics Mini Project

Sri Lanka Tourism Big Data Intelligence and Recommendation System

PySpark analytics and hybrid recommendations from tourist destination review data.

Problem and Objective

Turning tourism reviews into decision support

1

Analyze Demand

Find popular destinations and active tourism districts from review volume.

2

Measure Quality

Use sentiment, engagement, and confidence scoring to rank destinations fairly.

3

Recommend Places

Suggest destinations by district, travel theme, and TF-IDF text similarity.

Dataset

Sri Lankan destination reviews

  • Source file: Destination Reviews_(raw).csv
  • Columns: Destination, District, Timespan, Review
  • Raw text includes quotes, commas, multiline comments, and noisy characters.
  • Cleaning keeps valid districts and meaningful review text.

Spark Processing

End-to-end big data pipeline

1

Load

Read CSV using Spark with header, encoding, multiline, quote, and escape handling.

2

Clean

Remove missing values, invalid districts, very short reviews, and normalize text.

3

Engineer

Create sentiment, word engagement, recency segment, and travel theme features.

4

Aggregate

Build destination, district, theme, and TF-IDF recommendation outputs.

Part A Analytics

Demand, sentiment, and quality insights

  • Matale, Colombo, Hatton, and Matara show the strongest review activity.
  • Most reviews are positive or neutral, with a very small negative share.
  • Ranking uses more than popularity, so highly reviewed but weaker destinations are not automatically top.

Part B Recommendation System

Hybrid TF-IDF similarity recommender

  • Group all reviews into one destination profile.
  • Use Spark ML: Tokenizer, StopWordsRemover, HashingTF, IDF.
  • Calculate cosine similarity against the selected destination.
  • Blend text similarity with sentiment and popularity confidence.

Evaluation and Conclusion

A stronger analytics and recommendation project

Evaluation

  • Recommendation coverage: 236 destination profiles.
  • Uses implicit signals because user IDs and explicit ratings are unavailable.
  • Bayesian smoothing improves ranking reliability for small samples.

Future Improvements

  • Trained sentiment model instead of lexicon-only sentiment.
  • User ratings for collaborative filtering.
  • Maps, travel-time, seasonality, and traveller-profile filters.
